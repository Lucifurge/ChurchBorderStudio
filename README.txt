CHURCH BORDER STUDIO — PRODUCT WEBSITE
=====================================

Start at index.html. This is a static site; there is no npm install or build step.

TO ADD YOUR DOWNLOADS
1. Copy the built installer EXE from your Windows app dist folder to downloads/:
     Church-Border-Studio-Setup-16.0.0.exe
2. Optionally add:
     Church-Border-Studio-Portable-16.0.0.exe
3. Upload all website files with their folder structure intact.

The page checks for local installer files and only enables the button when a file
is available. If you store installers elsewhere, update site-config.js as shown
in DEPLOYMENT_GUIDE.md.

For a full publishing guide, open DEPLOYMENT_GUIDE.md.
