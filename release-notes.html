Public product page for version 16.0.0.

v16.0.0 · Production Edition

Current listed release

  • Redesigned desktop workspace with a keyboard-accessible navigation sidebar.
  • Curated color themes with search and category filters, plus custom saved looks.
  • Independent top, bottom, left, and right border visibility controls and configurable layout.
  • Motion effects including soft glow, pulse, heartbeat, sweep, breathe, and spectrum cycle.
  • OBS WebSocket audio meter and source selection for supported audio-reactive effects.
  • Local controller and overlay workflow intended to work alongside FreeShow and OBS Studio.
